# SUSTech Course Enrollment

> 面向 SUSTech 研究生的键盘驱动跨平台选课终端：缓存优先、候选队列循环抢课，并在登录态失效时自动续登。

面向研究生用户的 SUSTech TIS 终端选课工具。请从 Releases 下载与你的系统和处理器架构对应的版本，解压后直接运行，无需配置 YAML 文件或命令行参数。

## 开始使用

首次启动时按 `L` 打开“添加账户”，输入学号和密码。程序会验证研究生身份，并加载课程目录和已选课程。

账户验证完成后，候选课程可以在“全部”课程页加入，在“候选”页调整顺序并开始抢课。

## 界面操作

### 账户区

- `L` 登录/添加账户
- 登录验证过程中按 `Space` 取消登录
- 鼠标点击账户切换当前账户
- 账户行右侧的 `×` 删除账户

### 课程区

- `Tab` 切换“已选 / 候选 / 全部”
- `F` 筛选课程（课程名、代码、教学班、教师和上课时间均可搜索）
- “全部”页面：`Space` 添加课程
- “候选”页面：`Space` 移除课程
- “候选”页面：`[` / `]` 调整课程优先级
- `D` 打开当前课程详情
- `U` 更新课程；更新过程中再次按 `U` 取消更新
- 账户初次加载过程中按 `U` 取消加载

### 抢课与日志

- `Enter` 开始抢课；抢课过程中再次按 `Enter` 停止
- 抢课会按候选优先级循环提交，成功的课程会从候选中移除
- 课程尚未到选课时间时会停留等待，其余失败课程会继续循环
- 登录态失效时会自动重新获取登录态后继续抢课
- 日志区聚焦时按 `X` 清除日志

### 系统操作

- `C` 在账户、课程、日志区域之间切换焦点
- `S` 打开设置
- `Q` 或 `Esc` 打开退出确认
- `Ctrl+C` 立即退出程序

底部快捷键提示会根据当前焦点区域自动变化。鼠标可以点击课程标签、课程行和弹窗按钮。

## 设置

按 `S` 打开设置面板：

- 代理模式：跟随系统代理，或不使用代理
- 请求间隔：每次请求之间的间隔，单位为毫秒，范围为 `1` 到 `60000`

使用 `↑` / `↓` 切换字段，`Tab` 切换代理选项，`←` / `→` 切换确定或取消，`Enter` 选择按钮。

## 本地数据与缓存

程序会在可执行文件旁创建 `SustechCourseEnrollmentData` 目录，保存账户、候选课程、课程缓存、已保存设置和登录会话 Cookie。

密码交由系统凭据管理器保存，不写入账户 JSON。请妥善保护整个 `SustechCourseEnrollmentData` 目录，不要将其中的文件分享给他人。

启动时会优先使用有效的本地课程缓存，避免不必要的网络请求。按 `U` 才会主动更新已选课程和全部课程；候选顺序会立即保存。

## 使用须知

- 目前只支持研究生账户。
- 请仅使用本人的账户，并遵守学校 TIS 的使用规则和访问频率限制。
- 选课结果以 TIS 返回的信息为准。
